# Реализация аксессуара "Часы" для Jumpsuit

## Описание
Добавлен новый тип аксессуара - наручные часы, которые можно прикреплять к jumpsuit как галстук или другие аксессуары. Включает обычные часы для всех и специальные тактические часы для командиров.

## Что было сделано

### 1. Создание новых предметов часов
В файле `/code/modules/clothing/under/ties.dm` добавлены:

- `watch` - обычные часы
- `watch/gold` - золотые часы  
- `watch/digital` - цифровые часы
- `watch/tactical` - **ТАКТИЧЕСКИЕ КОМАНДИРСКИЕ ЧАСЫ** с расширенным функционалом

### 2. Функциональность

#### Обычные часы:
- При осмотре (examine) показывают текущее игровое время
- При активации (клик по предмету в руке) выводят время в чат
- Используют функцию `worldtime2text()` для отображения времени

#### 🎖️ ТАКТИЧЕСКИЕ ЧАСЫ FIELD COMMANDER:
**Доступ:** Только для командных ролей (Field Commander, Captain, Executive Officer, Staff Officer)

**Основные функции:**
1. **Show Time** - Расширенный дисплей времени с информацией о миссии
2. **Mission Status** - Полный статус миссии и активных целей
3. **Squad Coordinates** - Показ позиций всех squad members по областям
4. **Casualty Report** - Детальный отчет о потерях по squad'ам с процентами
5. **Squad Orders** - Быстрая отправка приказов выбранному squad или всем
6. **Set Objective** - Установка и отслеживание целей миссии
7. **Tactical Alert** - Экстренные уведомления для всех marines
8. **Emergency Functions** - Критические команды (эвакуация, abort миссии)

**Автоматические функции:**
- Отслеживание времени миссии с момента надевания
- Автоматические предупреждения о критических потерях в squad'ах (≤30% выживших)
- Периодические проверки статуса каждые 2 минуты

### 3. Интеграция с системой аксессуаров
- Часы добавлены в список разрешенных аксессуаров для jumpsuit в `/code/modules/clothing/under/under.dm`
- Используется существующая система attachment с слотом `ATTACHMENT_SLOT_UNIFORM_TIE`

### 4. Доступность в игре

#### Обычные часы:
Добавлены в торговый автомат униформы (`/obj/machinery/vending/uniform_supply`) в разделе "Accessories":
- Обычные часы: неограниченно (-1)
- Золотые часы: ограниченное количество (2)  
- Цифровые часы: неограниченно (-1)

#### Тактические часы:
Доступны только в **Командирском торговом автомате** (`/obj/machinery/marine_selector/clothes/commander`):
- Требует ACCESS_MARINE_COMMANDER
- Добавлены в `/code/__DEFINES/loadout/clothes/field_commander.dm`
- Категория: CAT_STD (Standard), цвет: оранжевый (указывает на специальное снаряжение)

## Использование в игре

### Обычные часы:
1. Получите часы из торгового автомата униформы
2. Наденьте jumpsuit
3. Используйте часы на jumpsuit (или используйте контекстное меню)
4. Часы прикрепятся как аксессуар
5. Осматривайте часы или активируйте их в руке для просмотра времени

### 🎖️ Тактические часы (Field Commander):
1. **Получение:** Только из командирского автомата (нужен командирский доступ)
2. **Установка:** Прикрепить к jumpsuit как обычный аксессуар
3. **Активация:** Клик по часам в руке → выбрать нужную функцию
4. **Автоматика:** Часы сами отслеживают миссию и предупреждают о проблемах

#### Примеры использования:
- **Перед боем:** Установить цели миссии, проверить статус squad'ов
- **Во время боя:** Давать быстрые приказы, отслеживать потери
- **Критические ситуации:** Запросить эвакуацию, объявить abort миссии
- **После боя:** Просмотреть casualty report, установить новые цели

## Требуемые спрайты

Для полной реализации необходимо добавить спрайты в следующие файлы:
- `/icons/obj/clothing/ties.dmi` - иконки предметов:
  - `watch` - обычные часы
  - `watch_gold` - золотые часы  
  - `watch_digital` - цифровые часы
  - `watch_tactical` - **тактические часы (с дисплеем, антеннами, более "военный" вид)**
- `/icons/obj/clothing/ties_overlay.dmi` - оверлеи для jumpsuit (те же названия)
- `/icons/mob/ties.dmi` - спрайты на персонаже (те же названия)

**Рекомендации для тактических часов:**
- Более крупный корпус с дисплеем
- Военная расцветка (зеленый/черный)
- Дополнительные элементы (антенна, кнопки)
- Светящиеся элементы для "высокотехнологичного" вида

## Технические детали

### Архитектура:
- **Базовый класс:** `/obj/item/clothing/tie` - наследование от системы галстуков/аксессуаров
- **Attachment система:** Используется `ATTACHMENT_SLOT_UNIFORM_TIE` для крепления к jumpsuit
- **Доступ:** Проверка через `is_command_job()` для тактических функций

### Тактические часы - особенности:
- **Таймеры:** Автоматический loop timer каждые 30 секунд для обновлений
- **Отслеживание:** Mission objectives хранятся в assoc list с временными метками
- **Squad integration:** Прямое взаимодействие с `SSteams.squads` и `squad.marines_list`
- **Уведомления:** Использование `span_boldannounce()` и звуковых эффектов
- **UI:** TGUI input dialogs для пользовательского ввода

### Безопасность:
- Все тактические функции требуют командирский доступ
- Проверка на живых персонажей перед отправкой сообщений
- Защита от спама через ограничения времени

### Производительность:
- Ленивые проверки squad status (только каждые 2 минуты)
- Умные фильтры для предотвращения спама в чате
- Автоматическая очистка таймеров при удалении объекта

Код полностью совместим с существующей системой и расширяет функциональность без breaking changes.
